# anti-pub-YouTube

Redirige automatiquement les vidéos YouTube vers `yout-ube.com`.

Exemple : `https://www.youtube.com/watch?v=G8ZGk1m5apY` → `https://www.yout-ube.com/watch?v=G8ZGk1m5apY`

La redirection s'applique :
- aux clics sur une vidéo depuis YouTube ;
- aux liens YouTube ouverts depuis un autre site (Google, messages…) ;
- aux liens courts `youtu.be/...`.

Les Shorts ne sont pas redirigés.

## Chrome

1. Ouvre `chrome://extensions`.
2. Active le **Mode développeur**.
3. Clique sur **Charger l'extension non empaquetée** et choisis le dossier `chrome-extension`.

## Safari

1. Installe l'app gratuite [Userscripts](https://apps.apple.com/app/id1463298887) depuis l'App Store.
2. Dans l'app, choisis le dossier `safari` avec **Change Userscripts Directory**.
3. Dans Safari → Réglages → Extensions, active **Userscripts** et autorise-la sur YouTube.

> `yout-ube.com` est un service tiers, non affilié à YouTube.
